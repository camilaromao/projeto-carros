# Projeto Carros 🚗

Projeto desenvolvido durante meus estudos de desenvolvimento front-end, com o objetivo de praticar HTML, JavaScript e Bootstrap.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** personalização visual e controle das dimensões dos elementos.
- **JavaScript:** criação dinâmica dos cartões de veículos, manipulação do DOM e implementação de interações.
- **Bootstrap:** organização do layout responsivo e estilização dos componentes.
- **Bootstrap Icons:** utilização de ícones para os botões de interação.

## ✨ Funcionalidades

- Exibição dinâmica dos veículos.
- Apresentação do nome, da imagem e da descrição de cada carro.
- Janela de detalhes para visualizar informações do veículo selecionado.
- Alternância entre os temas claro e escuro.
- Layout adaptável a diferentes tamanhos de tela.

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei a manipulação do DOM, o uso de funções, a iteração de arrays, os eventos de clique e a utilização de componentes do Bootstrap.

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento front-end.
